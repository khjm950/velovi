Velovi — Android PWA prototype
===============================

التثبيت:
1. استضف ملفات المشروع على HTTPS.
2. افتح الرابط في Chrome على Android.
3. استخدم قائمة المتصفح واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»، أو زر «تثبيت Velovi» إذا ظهر.

ملاحظات مهمة:
- لا يُنصح بفتح index.html مباشرة من مدير الملفات؛ يلزم HTTPS أو localhost.
- هذه نسخة واجهة تجريبية وليست تطبيقاً مالياً جاهزاً للاستخدام الحقيقي.
- الأرصدة والحركات المعروضة أمثلة توضيحية فقط.
- لا يوجد تسجيل دخول أو حفظ دائم أو مزامنة أو صلاحيات حقيقية أو اتصال فعلي بـSupabase أو البنك.
- اختيار ملف كشف الحساب لا يعني قراءته أو استيراده.
- لا تدخل بيانات مالية حقيقية أو كلمات مرور أو رموز تحقق.

قبل الاستخدام الحقيقي يجب تصميم واختبار المصادقة وسياسات الوصول والتشفير وحفظ البيانات والمزامنة.
