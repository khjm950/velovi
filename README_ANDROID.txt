Velovi Android-ready PWA package
=================================

ما الذي أُضيف؟
- أيقونات Android بمقاسي 192 و512 بكسل.
- ملف manifest محسّن للتثبيت كتطبيق PWA.
- Service Worker محسّن للتخزين المؤقت والعمل دون اتصال بعد أول زيارة.
- زر تثبيت يظهر تلقائياً عندما يسمح Chrome بالتثبيت.

طريقة التشغيل والتثبيت على Android:
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS (وليس ملف ZIP نفسه).
2. افتح رابط الموقع في Google Chrome على الهاتف.
3. انتظر تحميل الصفحة مرة واحدة، ثم افتح قائمة ⋮ واختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
4. إذا ظهر زر "تثبيت Velovi" داخل الصفحة، يمكنك استخدامه أيضاً.

مهم جداً:
- لا يمكن تثبيت PWA بشكل موثوق بفتح index.html مباشرة من مدير الملفات؛ يلزم HTTPS أو localhost.
- هذه النسخة ما زالت نموذج واجهة ببيانات تجريبية فقط.
- لا يوجد اتصال بـSupabase أو ING، ولا تسجيل دخول أو صلاحيات حقيقية أو حفظ مالي آمن.
- لا تدخل كلمات مرور بنكية أو بيانات مالية حقيقية.
- المزامنة السحابية والتشفير والنسخ الاحتياطي وربط ING ستُنفّذ في مرحلة لاحقة.

للاستخدام الحقيقي يجب إعداد الاستضافة، ثم إعداد Supabase والمصادقة والتشفير واختبارات الأمان قبل إدخال أي بيانات حقيقية.
