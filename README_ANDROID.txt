Velovi — Android APK build
==========================

حالة المشروع
------------
التطبيق الحالي مرتبط بـ Supabase ويستخدم تسجيل الدخول وRLS للحماية.
هذه الحزمة ليست نسخة البيانات التجريبية القديمة. لا تدخل بيانات مالية حقيقية
قبل إكمال اختبارات القبول على جهاز فعلي ومراجعة النسخة النهائية.

إنشاء APK تجريبي قابل للتثبيت
------------------------------
يُبنى APK عبر GitHub Actions باستخدام Capacitor 8:

1. افتح المستودع في GitHub.
2. انتقل إلى Actions.
3. اختر "Velovi Android APK".
4. اضغط "Run workflow" على فرع chore/velovi-stability-apk.
5. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل artifact باسم velovi-debug-apk.
6. فك ضغط الملف وثبّت app-debug.apk على جهاز Android.

متطلبات البناء المعتمدة:
- Node.js 22
- Java 21
- Android SDK 36
- Capacitor 8.6.2

ملاحظات قبل الاستخدام:
- APK الناتج حالياً نسخة Debug للاختبار، وليس إصداراً موقعاً للنشر في Google Play.
- لا يُنشأ مفتاح توقيع خاص ولا يُحفظ أي سر توقيع في المستودع.
- يتطلب تسجيل الدخول والبيانات المالية اتصالاً بالإنترنت وخدمة Supabase.
- ملفات OCR وPDF تُحمّل من CDN عند الحاجة؛ لذلك قراءة الكشوف تحتاج اتصالاً بالإنترنت.
- نسخة APK تستخدم ملفات الواجهة المجمعة محلياً، مع استمرار اتصالها بخدمات Supabase.
- اختبار الكاميرا، اختيار الملفات، لوحة المفاتيح، الرجوع من النوافذ، ودورة حياة التطبيق
  يجب أن يتم على هاتف Android فعلي قبل اعتماد الإصدار.

لإصدار Release موقّع:
يجب إعداد keystore خاص خارج المستودع، ثم تخزين بياناته في GitHub Actions Secrets.
لا تستخدم keystore الاختبار أو تضع كلمات مروره في ملفات المشروع أو المحادثة.
